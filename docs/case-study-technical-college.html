Case Study · Technical Education

Tool organization that runs itself — Bridgerland Technical College

When Bridgerland Technical College needed to bring order to its lab tool storage, the conventional fix didn't hold. Here's what changed when each tool got a dedicated place — and why students started putting tools back on their own.

The Challenge

The conventional fix didn't hold.

The instructors had already tried the obvious approach: painting tool locations directly onto the storage. It didn't last. Tools migrated between stations, students couldn't tell what was missing, and the system quietly broke down.

"We tried painting tool locations with blue and yellow spots. Students couldn't find things and it ended up a mess. The foam is more intuitive — you pull the drawer, you see what's missing, and you know exactly where it goes back."

Jeff Waddoups Bridgerland Technical College

Problem

Painted markers didn't stick

Blue and yellow location spots were painted on, but students still couldn't find what they needed — and it ended up a mess.

Problem

Tools migrated

With no fixed home for each tool, items drifted between stations and the standard slowly eroded.

Problem

Missing tools weren't obvious

There was no quick way to tell what was gone, so accountability depended on someone noticing.

The Process

From tool inventory to drop-in install.

Every kit was measured and designed individually — no templates, no compromise on fit.

Tool Inventory

We documented the lab's tools and drawers on site, capturing each layout so every tool could be mapped to a dedicated location.

AI Layout Design

Each kit's tools were mapped individually. AI-generated cut paths positioned every tool for an optimal fit within the existing drawer dimensions — no dead space, no shifting.

CNC Production

Two-tone XLPE foam cut to sub-millimeter precision in Logan, Utah. Each pocket fits exactly one tool — one way. Wrong tool won't seat.

Install & Handoff

The finished inserts dropped straight into the existing drawers — no adjustments, no setup. From there, the foam did the teaching.

The Outcome

"It's 10 times better than what it was."

With each tool in a dedicated, labeled location, a missing tool became obvious at a glance and putting it back became automatic. Most telling: students returned tools on their own, without being asked. Organization stopped being a rule to enforce and became the natural way the lab works.

Result

Students self-manage

"The students are putting them back intuitively and naturally. I haven't told them to do it — it just happened."

Result

Missing tools are obvious

"You can see without any effort — this is the only thing left out. Everything else is put away."

Result

No more hunting

"Students aren't wondering where the tools are. They don't come to us — it's just there."

"This one has been exceptional. It's 10 times better than what it was."

Jeff Waddoups Bridgerland Technical College
